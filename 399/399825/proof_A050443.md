# A050443 に関する恒等式の証明

[OEIS A050443](https://oeis.org/A050443) を $`a(m)`$ と書く。任意の整数 $`n \ge 0`$ に対して、次の恒等式が成り立つ。

```math
\sum_{j=0}^{n}
\frac{(3n+j)!}{(3n-3j)!(4j+1)!}
=
\frac{a(12n+3)}{12n+3}.
```

## 1. 対数母関数

数列 $`a(m)`$ は

```math
a(0)=4,\qquad a(1)=a(2)=0,\qquad a(3)=3,
```

および、$`m \ge 4`$ に対する漸化式

```math
a(m)=a(m-3)+a(m-4)
```

で定義される。この漸化式の特性多項式は

```math
q(t)=t^4-t-1
```

である。その根を $`r_1,r_2,r_3,r_4`$ とすると、Newton の恒等式から

```math
a(m)=\sum_{i=1}^{4} r_i^m
```

が成り立つ。また、$`q(t)`$ の相反多項式は

```math
P(x)=x^4q(1/x)=1-x^3-x^4
=\prod_{i=1}^{4}(1-r_i x)
```

である。したがって、対数微分により

```math
\begin{aligned}
-\frac{P'(x)}{P(x)}
&=\sum_{i=1}^{4}\frac{r_i}{1-r_i x} \\
&=\sum_{m=1}^{\infty}a(m)x^{m-1} \\
&=\frac{3x^2+4x^3}{1-x^3-x^4}.
\end{aligned}
```

両辺を $`0`$ から $`x`$ まで形式的に積分すると、

```math
\sum_{m=1}^{\infty}\frac{a(m)}{m}x^m
=
\log\!\left(\frac{1}{1-x^3-x^4}\right)
```

を得る。

## 2. 係数抽出

$`\log(1-y)^{-1}=\sum_{k\ge1}y^k/k`$ に $`y=x^3+x^4=x^3(1+x)`$ を代入すると、

```math
\begin{aligned}
\log\!\left(\frac{1}{1-x^3-x^4}\right)
&=\sum_{k=1}^{\infty}\frac{x^{3k}(1+x)^k}{k} \\
&=\sum_{k=1}^{\infty}\sum_{i=0}^{k}
  \frac{1}{k}\binom{k}{i}x^{3k+i}.
\end{aligned}
```

$`x^m`$ の係数を比較する。条件 $`m=3k+i`$ と $`0\le i\le k`$ は $`3k\le m\le4k`$ と同値なので、

```math
\frac{a(m)}{m}
=
\sum_{\substack{k\ge1\\3k\le m\le4k}}
\frac{1}{k}\binom{k}{m-3k}.
```

ここで $`m=12n+3`$ とする。このとき $`k`$ の範囲は

```math
3n+1
=
\left\lceil\frac{12n+3}{4}\right\rceil
\le k\le
\left\lfloor\frac{12n+3}{3}\right\rfloor
=
4n+1.
```

$`k=3n+j+1`$ と置けば、$`0\le j\le n`$ であり、

```math
m-3k=3n-3j.
```

よって、各項は

```math
\begin{aligned}
\frac{1}{k}\binom{k}{m-3k}
&=\frac{1}{3n+j+1}\binom{3n+j+1}{3n-3j} \\
&=\frac{(3n+j)!}{(3n-3j)!(4j+1)!}.
\end{aligned}
```

以上を係数公式に代入すると、

```math
\frac{A050443(12n+3)}{12n+3}
=
\sum_{j=0}^{n}
\frac{(3n+j)!}{(3n-3j)!(4j+1)!}
```

が得られる。
