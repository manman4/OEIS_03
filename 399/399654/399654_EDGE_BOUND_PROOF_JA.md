# A399654 の探索で用いる辺数上限

単純グラフ `G` のサイクル長集合を

```text
CS(G) = { L : G は長さ L のサイクルを含む }
```

とする。`399654_01.c` と `399654_03.c` は、候補となる集合 `S` が
`CS(G) = S` として実現可能かを調べる際に、次の辺数上限を用いている。

## 補題

`S` が高々 `n` 頂点の単純グラフによって実現可能ならば、

```text
|E(H)| <= sum_{L in S} L
```

を満たし、かつ `CS(H) = S` となる高々 `n` 頂点の単純グラフ `H` が存在する。

`S` が空集合の場合は、辺を持たないグラフを取ればよい。以下では `S` が
空でない場合を考える。

## 証明

`CS(G) = S` を満たす高々 `n` 頂点の単純グラフ `G` を一つ取る。辺を削除しても
サイクル長集合が `S` のままである限り辺を削除し続け、辺に関して極小な部分
グラフ `H` を取る。すなわち、

```text
CS(H) = S
```

であり、どの辺 `e` に対しても

```text
CS(H - e) != S
```

である。

辺の削除によって新しいサイクルが生じることはないので、
`CS(H - e)` は `S` の部分集合である。したがって各辺 `e` について、
`H - e` では失われる長さ `L(e) in S` が少なくとも一つ存在する。

これは、`H` に含まれるすべての長さ `L(e)` のサイクルが辺 `e` を通ることを
意味する。実際、`e` を通らない長さ `L(e)` のサイクルが一つでもあれば、その
サイクルは `H - e` にも残るためである。

ここで、各 `L in S` について、`H` に含まれる長さ `L` のサイクルを一つ選び、
それを `C_L` と書く。任意の辺 `e in E(H)` に対し、上で得た `L(e)` を考えると、
すべての長さ `L(e)` のサイクルが `e` を通るので、選んだ `C_{L(e)}` も `e` を
含む。よって

```text
E(H) = union_{L in S} E(C_L).
```

したがって、和集合で重複する辺を別々に数えることで、

```text
|E(H)|
  = |union_{L in S} E(C_L)|
 <= sum_{L in S} |E(C_L)|
  = sum_{L in S} L.
```

以上で補題が示された。

## プログラムへの適用

- `399654_01.c` では、探索中のグラフの辺数が `sum_{L in S} L` を超えた枝を
  打ち切る。探索は辺を追加する方向にだけ進むので、その枝から上の補題の
  辺極小な実現グラフへ到達することはなく、この枝切りは解を失わない。
- `399654_03.c` では、SAT によって探索するグラフの辺数を最初から
  `sum_{L in S} L` 以下に制限する。`S` が実現可能ならば補題を満たす実現
  グラフが少なくとも一つ存在するので、この制約も充足可能性を変えない。

この補題が主張するのは、辺数上限を満たす実現グラフが**存在する**ということ
である。同じサイクル長集合 `S` を持つすべてのグラフがこの上限を満たす、と
いう主張ではない。

また、選んだ `|S|` 個のサイクルが全辺を被覆することから、サイクル空間の次元
が `|S|` 以下であるとは限らない。したがって、この証明から
`mu(H) <= |S|`（`mu(H)` はサイクロマティック数）を導くことはできない。

頂点数が `n` 未満の実現グラフが得られた場合は孤立頂点を追加できる。孤立頂点
はサイクル長集合を変えないので、「高々 `n` 頂点」と「ちょうど `n` 頂点」の
違いはこの計算には影響しない。
