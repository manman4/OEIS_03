# Erdős problem #84 日本語訳（非公式）

出典:

- [Erdős problem #84](https://www.erdosproblems.com/84)
- [GitHub Issue #290: Computing sequence for Erdős problem #84](https://github.com/teorth/erdosproblems/issues/290)

## 問題文

`n` 個の頂点をもつグラフ `G` の**サイクル長集合**とは、次の条件を満たす集合

```text
A ⊆ {3, …, n}
```

のことである。

すなわち、`A` は `G` に含まれるサイクルの長さを、重複なくすべて集めた集合である。

このような集合 `A` として可能なものの個数を `f(n)` とする。

次を証明せよ。

```text
f(n) = o(2^n)
```

また、次を証明せよ。

```text
f(n) / 2^(n/2) → ∞
```

## 訳語について

英語の *cycle set* を単に「サイクル集合」と訳すと、サイクルそのものを要素とする集合にも読める。この問題で集合 `A` の要素となるのはサイクルの**長さ**なので、この文書では「サイクル長集合」と訳す。

## 今回の計算との関係

GitHub Issue #290は、問題全体の漸近的な主張を証明することではなく、関連する整数列

```text
f(3), f(4), f(5), …
```

の小さい値を計算する作業を募集している。

二つの独立な小規模列挙とnautyによる非同型グラフ列挙によって、`n = 3, …, 9` について次の値を再現した。

```text
f(3), f(4), f(5), f(6), f(7), f(8), f(9) = 2, 4, 6, 11, 21, 40, 75
```

計算方法、実行環境、各サイクル長集合の実現グラフについては、同じディレクトリの `README.md`、`ISSUE_290_REPORT.md`、および二つの `results_*.json` を参照する。
