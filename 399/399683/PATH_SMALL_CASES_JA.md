# パスの反Ramsey数における `k=3,4` の場合

このノートは、OEIS候補の三角配列

```text
T(n,k) = AR(n,P_k),  3 <= k <= n
```

に含める小さい場合

```text
T(n,3) = 1                    (n >= 3),
T(4,4) = 3,
T(n,4) = 2                    (n >= 5)
```

の初等的な証明を記録する。ここで `P_k` は `k` 頂点のパスであり、
`AR(n,P_k)` は、虹色の `P_k` を含まない `K_n` の辺彩色で使用できる色数の
最大値である。より正確には、辺彩色を `c` とするとき、その色数は像の大きさ
`|c(E(K_n))|`、すなわち実際に使用される色の個数を指す。虹色とは、コピーを
構成するすべての辺の色が互いに異なることをいう。

Long-Tu Yuanの公式が直接扱う範囲は `n >= k >= 5` である。そのため、
以下の `k=3,4` の場合は公式から導くのではなく、定義から別に証明する。

## 補題: 異色の隣接辺

2色以上を使用した完全グラフの辺彩色には、互いに異なる色をもつ隣接2辺が
存在する。

実際、異なる色の2辺を選ぶ。それらが隣接していればよい。互いに素な辺
`ab` と `cd` なら、辺 `bc` を考える。`bc` の色が `ab` の色と異なれば
`ab,bc` が求める2辺であり、同じなら `bc,cd` が求める2辺である。

## `T(n,3) = 1` (`n >= 3`)

1色だけを使う彩色には虹色の `P_3` がないので、`T(n,3) >= 1` である。

一方、2色以上を使うと、上の補題により異色の隣接2辺が存在する。その2辺は
虹色の `P_3` を構成する。したがって虹色の `P_3` を避ける彩色は1色しか
使用できず、

```text
T(n,3) = 1
```

となる。

## `T(4,4) = 3`

### 下界

`K_4` の頂点を `1,2,3,4` とし、次の3つの完全マッチングをそれぞれ別の
色で塗る。

```text
{12,34},  {13,24},  {14,23}.
```

`K_4` の任意の `P_4` では、最初と最後の辺が互いに素である。この彩色では
互いに素な2辺は同じ完全マッチングに属して同色になるため、虹色の `P_4` は
存在しない。よって `T(4,4) >= 3` である。

### 上界

4色以上を使う彩色から、異なる4色をもつ辺を1本ずつ選び、それらからなる
4頂点の単純グラフ `H` を考える。`H` は4辺をもつ。

4頂点4辺の単純グラフは必ず `P_4` を含む。実際、非連結なら辺数は高々3本
なので `H` は連結である。`H` の全域木が `P_4` なら終了である。全域木が
星 `K_{1,3}` なら、残る4本目の辺は星の2つの葉を結び、その辺と星の2辺から
`P_4` が得られる。

選んだ4辺の色はすべて異なるので、`H` に含まれる `P_4` は虹色である。
したがって `T(4,4) <= 3` であり、

```text
T(4,4) = 3
```

となる。

## `T(n,4) = 2` (`n >= 5`)

### 下界

例えば1辺だけを色 `beta`、残りの辺を色 `alpha` とすれば、ちょうど2色を
使用する。`P_4` は3辺をもつため、この彩色に虹色の `P_4` は存在しない。
よって `T(n,4) >= 2` である。

### 上界

3色以上を使いながら虹色の `P_4` を含まない `K_n` の辺彩色があると仮定
する。補題により異色の隣接辺が存在するので、その色を `alpha,beta` とし、

```text
color(ab) = alpha,  color(bc) = beta
```

とおく。彩色には3色以上が使われているので、`alpha,beta` と異なる使用色
`gamma` が存在する。`X = V(K_n) \ {a,b,c}` とおくと、`n >= 5` より
`|X| >= 2` である。各 `x` in `X` について、パス `x-a-b-c` と
`a-b-c-x` が虹色でないことから、

```text
color(ax), color(cx) are in {alpha,beta}.
```

したがって、色 `gamma` の辺は次の3種類のいずれかである。

1. `ac`。
2. `bx` (`x` in `X`)。
3. `xy` (`x,y` in `X`)。

以下、それぞれが矛盾を導くことを示す。

### 場合1: `color(ac) = gamma`

各 `x` in `X` について、`x-a-c-b` と `b-a-c-x` が虹色でないことから、

```text
color(ax) = beta,  color(cx) = alpha.
```

異なる `x,y` in `X` を選ぶ。パス `a-x-y-c` と `x-y-a-c` が虹色でない
ことから、`color(xy) = beta` となる。しかし `a-c-y-x` の3辺の色は順に
`gamma,alpha,beta` であり、これは虹色の `P_4` である。矛盾。

### 場合2: `color(bx) = gamma`

ある `x` in `X` について `color(bx) = gamma` と仮定する。以下の議論は、
そのような `x` が1つ存在することだけを使用する。

パス `a-b-x-c` と `c-b-x-a` が虹色でないことから、

```text
color(cx) = alpha,  color(ax) = beta.
```

`y` in `X \ {x}` を選ぶ。パス `y-a-x-b` と `y-c-x-b` から、

```text
color(ay) = beta,  color(cy) = alpha.
```

さらに `a-y-x-b` と `c-y-x-b` から `color(xy) = gamma` となる。すると
`a-x-y-c` の3辺の色は順に `beta,gamma,alpha` となり、虹色の `P_4` が
得られる。矛盾。

### 場合3: `color(xy) = gamma`

パス `a-b-x-y` が虹色でないことから
`color(bx)` は `alpha` または `gamma` である。一方、`c-b-x-y` が虹色で
ないことから、`color(bx)` は `beta` または `gamma` である。したがって
`color(bx) = gamma` となり、場合2に帰着して矛盾する。

以上により第3の色は存在できないので `T(n,4) <= 2` である。下界と合わせて

```text
T(n,4) = 2  (n >= 5)
```

を得る。

## `n` に関する非単調性

`k` を固定しても `T(n,k)` は `n` について単調非減少とは限らない。実際、

```text
T(4,4) = 3,  T(5,4) = 2.
```

`K_4` では3つの完全マッチングによる3色彩色が可能だが、頂点が5個以上に
なると、上で示したように第3色が必ず虹色の `P_4` を生じさせる。この低下は
誤植ではなく、小さい場合に固有の例外である。

## 計算による照合

この証明とは独立に、このディレクトリのPython全探索とCの枝刈り探索は
`n <= 7` について同じ値を与える。全探索は小さい場合の再現確認であり、
上記の証明は任意の `n >= 5` に対して成り立つ。
