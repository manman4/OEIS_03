# 最初の隣接差が最小部分以下である、隣接差が非増加の分割

## 結論と定義

各部分を小さい順に並べた分割

```math
1\le b_1\le b_2\le\cdots\le b_k
```

について、隣接差が非増加で、最初の隣接差が最小部分以下であるとする。すなわち、部分が2個以上の場合の条件は

```math
b_1\ge b_2-b_1\ge b_3-b_2\ge\cdots\ge b_k-b_{k-1}\ge0.
```

このような分割の個数を $`a(n)`$ とすると、提示された母関数は正しい。

```math
\sum_{n\ge0}a(n)x^n=1+\sum_{k\ge1}(\prod_{j=1}^{k}\frac{1}{1-x^{(k-j+1)(k+j)/2}}-1).
```

ここで、空分割を含めて $`a(0)=1`$ とし、部分が1個の場合には差の条件を課さない。和の各項の中で、積から1を引く。

## 証明

部分の個数 $`k\ge1`$ を固定し、最初の部分と隣接差をまとめて

```math
t_1=b_1,\qquad t_i=b_i-b_{i-1}\quad(2\le i\le k)
```

とおく。分割の条件は

```math
t_1\ge t_2\ge\cdots\ge t_k\ge0,\qquad t_1\ge1
```

と同値である。

補助的に $`t_{k+1}=0`$ と定め、

```math
e_r=t_r-t_{r+1}\quad(1\le r\le k)
```

とおく。すると各 $`e_r`$ は非負整数であり、少なくとも1個は正である。逆に、このような任意の組から

```math
t_i=\sum_{r=i}^{k}e_r,\qquad b_i=\sum_{s=1}^{i}t_s
```

によって、条件を満たす正の部分からなる分割が一意に復元される。したがって、これらのパラメータと対象の分割は一対一に対応する。

分割の総和は

```math
n=\sum_{i=1}^{k}b_i=\sum_{i=1}^{k}(k-i+1)t_i=\sum_{r=1}^{k}e_r\sum_{i=1}^{r}(k-i+1)=\sum_{r=1}^{k}\frac{r(2k-r+1)}{2}e_r.
```

各 $`e_r`$ を独立に非負整数全体で動かした母関数は

```math
\prod_{r=1}^{k}\frac{1}{1-x^{r(2k-r+1)/2}}.
```

ただし、すべての $`e_r`$ が0の組では、すべての部分が0となる。この組だけを除くために1を引く。よって、部分がちょうど $`k`$ 個の対象分割の母関数は

```math
\prod_{r=1}^{k}\frac{1}{1-x^{r(2k-r+1)/2}}-1.
```

積の添字を $`j=k-r+1`$ と置き換えると、

```math
\frac{r(2k-r+1)}{2}=\frac{(k-j+1)(k+j)}{2}.
```

空分割の寄与1を加え、すべての $`k\ge1`$ について足し合わせれば、提示の公式を得る。

各重みは $`k`$ 以上で、$`r=1`$ のとき $`k`$ である。したがって、1を引いた各項の最低次数は $`k`$ となる。任意の次数に寄与する項は有限個なので、この無限和は形式的冪級数として定義できる。

## 独立検証

Python の整数演算で、総和が40以下の全分割を列挙し、隣接差の非増加条件と最初の差の上限を直接判定した。提示の母関数を別途展開した係数と比較し、総和と部分の個数の各組についてすべて一致した。

初項は次のとおりである。

```math
(a(0),\ldots,a(20))=(1,1,2,3,3,4,6,4,6,8,7,8,11,7,12,14,10,13,19,12,18).
```

例えば、4の対象分割は次の3個である。

```math
(4),\quad(2,2),\quad(1,1,1,1).
```

分割 $`(1,3)`$ は最初の差が2で最小部分1を超えるため除外される。分割 $`(1,1,2)`$ は隣接差が $`0,1`$ で増加するため除外される。

有限範囲の照合は補助的な検証であり、全次数に対する正しさは上の一対一対応による。

## 並べ方について

英語の題名 “Number of partitions of n such that the successive differences of consecutive parts are nonincreasing, and first difference <= first part.” は、ここでは部分を小さい順に並べて解釈した。大きい順の部分について正の向きの差を取る場合とは条件が異なる。
