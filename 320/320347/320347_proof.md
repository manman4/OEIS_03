# A320347 の g.f.（Vladeta Jovovic, Nov 24 2026）の証明

## 主張

$`a(n)`$ は、$`n`$ を相異なる部分 $`a_1 > a_2 > \cdots > a_m`$ に分割したもののうち、差 $`a_1 - a_2, \ldots, a_{m-1} - a_m`$ がすべて異なるものの個数である。このとき

```math
\sum_{n \ge 1} a(n)\, x^n = \sum_{m \ge 1} \frac{x^m}{1 - x^m} \left[ y_1 \cdots y_{m-1} \right] \prod_{j \ge 1} \left( 1 + \sum_{i=1}^{m-1} y_i\, x^{ij} \right).
```

## 証明

### 1. 分割を（最小部分, 差の列）で表す

部分の個数 $`m`$ を固定する。$`d_i = a_i - a_{i+1}`$（$`1 \le i \le m-1`$）とおくと $`d_i \ge 1`$ で

```math
a_k = a_m + \sum_{i=k}^{m-1} d_i .
```

$`k = 1, \ldots, m`$ について足すと、$`d_i`$ は $`k \le i`$ となる $`i`$ 個の $`a_k`$ に現れるので

```math
n = \sum_{k=1}^{m} a_k = m\, a_m + \sum_{i=1}^{m-1} i\, d_i .
```

$`a_m \ge 1`$, $`d_i \ge 1`$ を満たす組 $`(a_m, d_1, \ldots, d_{m-1})`$ と、$`m`$ 個の部分からなる分割とは一対一に対応する。条件は「$`d_1, \ldots, d_{m-1}`$ が相異なる」ことだけである。

### 2. 最小部分の寄与

$`a_m \ge 1`$ は自由に選べて、重みは $`x^{m a_m}`$ である。よって寄与は

```math
\sum_{a \ge 1} x^{ma} = \frac{x^m}{1 - x^m} .
```

### 3. 差の列の寄与

```math
P_m = \prod_{j \ge 1} \left( 1 + \sum_{i=1}^{m-1} y_i\, x^{ij} \right)
```

とおく。この積を展開すると、各 $`j \ge 1`$ について「何も選ばない（因子 $`1`$）」か「$`i`$ を1つ選ぶ（因子 $`y_i x^{ij}`$）」のどちらかを選ぶことになる（有限個の $`j`$ を除いて $`1`$ を選ぶ）。

$`[y_1 \cdots y_{m-1}]`$ を取ると、各 $`i = 1, \ldots, m-1`$ がちょうど1回ずつ選ばれた項だけが残る。$`i`$ が選ばれた $`j`$ を $`d_i`$ と書くと、次のことが言える。

- 1つの $`j`$ では高々1つの $`i`$ しか選べないので、$`d_1, \ldots, d_{m-1}`$ は相異なる。
- 各 $`i`$ はちょうど1回選ばれるので、$`d_i`$ は一意に決まる。
- その項の $`x`$ の指数は $`\sum_i i\, d_i`$ である。

逆に、相異なる正整数 $`d_1, \ldots, d_{m-1}`$ に対しては、$`j = d_i`$ で $`i`$ を選び、それ以外の $`j`$ で $`1`$ を選ぶ項がただ1つある。よって

```math
\left[ y_1 \cdots y_{m-1} \right] P_m = \sum_{\substack{d_1, \ldots, d_{m-1} \ge 1 \\ \text{distinct}}} x^{\sum_{i} i\, d_i} .
```

$`m = 1`$ のときは空の単項式なので定数項を取ることになり、値は $`1`$ である。

### 4. まとめ

2 と 3 の積を $`m \ge 1`$ について足すと、1 の式より $`\sum_{n} a(n)\, x^n`$ に等しい。 $`\blacksquare`$

注意: g.f. の定数項は $`0`$ で、数列の offset 1 と合っている。
