# A320347 の g.f.（Vladeta Jovovic, Nov 24 2026）の証明

## 主張

a(n) = 相異なる部分への n の分割 a_1 > a_2 > ... > a_m で、差 a_1-a_2, ..., a_{m-1}-a_m がすべて異なるものの個数。

G.f.: Sum_{m>=1} x^m/(1-x^m) * [y_1*...*y_(m-1)] Product_{j>=1} (1 + Sum_{i=1..m-1} y_i*x^(i*j)).

## 証明

### 1. 分割を (最小部分, 差の列) で表す

部分の個数 m を固定する。d_i = a_i - a_{i+1}（i = 1..m-1）とおくと、d_i >= 1 で

a_k = a_m + Sum_{i=k..m-1} d_i.

k = 1..m で足すと、d_i は k <= i となる i 個の a_k に現れるので

n = Sum_k a_k = m*a_m + Sum_{i=1..m-1} i*d_i.

(a_m, d_1, ..., d_{m-1}) と、a_m >= 1、d_i >= 1 を満たす m 個の部分の分割とは一対一に対応する。条件は「d_1, ..., d_{m-1} が相異なる」ことだけである。

### 2. 最小部分の寄与

a_m >= 1 は自由に選べて重みは x^{m*a_m}。よって寄与は Sum_{a>=1} x^{m a} = x^m/(1-x^m)。

### 3. 差の列の寄与

P_m = Product_{j>=1} (1 + Sum_{i=1..m-1} y_i x^{i j}) とおく。

この積を展開すると、各 j >= 1 について「何も選ばない（1）」か「i を1つ選んで y_i x^{i j}」のどちらかを選ぶことになる（有限個の j を除いて 1 を選ぶ）。

[y_1*...*y_(m-1)] を取ると、各 i = 1..m-1 がちょうど1回ずつ選ばれた項だけが残る。i が選ばれた j を d_i と書くと、

- 1つの j では高々1つの i しか選べないので、d_1, ..., d_{m-1} は相異なる。
- 各 i はちょうど1回選ばれるので、d_i は一意に決まる。
- その項の x の指数は Sum_i i*d_i。

逆に、相異なる正整数 d_1, ..., d_{m-1} に対しては、j = d_i で i を選び、それ以外の j で 1 を選ぶ項がただ1つある。よって

[y_1*...*y_(m-1)] P_m = Sum_{d_1..d_{m-1} 相異なる, >=1} x^{Sum_i i d_i}.

（m = 1 のときは空の単項式なので定数項を取ることになり、値は 1 である。）

### 4. まとめ

2 と 3 の積を m >= 1 について足すと、1 の式より Sum_n a(n) x^n に等しい。 ∎

注意: g.f. の定数項は 0 で、数列の offset 1 と合っている。
