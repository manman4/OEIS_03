# 隣接差が非増加である分割の母関数

## 結論と定義

分割の各部分を小さい順に並べ、

```math
1 \le b_1 \le b_2 \le \cdots \le b_k
```

とする。隣接差が

```math
b_2-b_1 \ge b_3-b_2 \ge \cdots \ge b_k-b_{k-1} \ge 0
```

を満たす分割の個数を $`a(n)`$ とする。この解釈では、提示された母関数は正しい。

```math
\sum_{n\ge0}a(n)x^n = 1+\sum_{k\ge1}\frac{x^k}{1-x^k}\prod_{j=1}^{k-1}\frac{1}{1-x^{(k-j)(k+j-1)/2}}.
```

空分割を含めて $`a(0)=1`$ とする。部分が1個または2個の場合、隣接差どうしの比較条件はない。空積は1とする。

## 証明

部分の個数 $`k\ge1`$ を固定する。最小の部分と隣接差を

```math
m=b_1\ge1,\qquad d_i=b_{i+1}-b_i\quad(1\le i\le k-1)
```

とおく。補助的に $`d_k=0`$ と定め、差の差を

```math
e_r=d_r-d_{r+1}\quad(1\le r\le k-1)
```

とおく。条件より、各 $`e_r`$ は非負整数である。

逆に、任意の整数 $`m\ge1`$ と非負整数 $`e_1,\ldots,e_{k-1}`$ から、

```math
d_i=\sum_{r=i}^{k-1}e_r,\qquad b_i=m+\sum_{t=1}^{i-1}d_t
```

によって条件を満たす分割が一意に復元できる。したがって、これらのパラメータと対象の分割は一対一に対応する。

分割の総和は

```math
n=\sum_{i=1}^{k}b_i=km+\sum_{i=1}^{k-1}(k-i)d_i.
```

ここに $`d_i=\sum_{r=i}^{k-1}e_r`$ を代入し、有限和の順序を入れ替えると、

```math
n=km+\sum_{r=1}^{k-1}e_r\sum_{i=1}^{r}(k-i)=km+\sum_{r=1}^{k-1}\frac{r(2k-r-1)}{2}e_r.
```

各パラメータは独立に動くので、部分がちょうど $`k`$ 個の分割の母関数は

```math
\frac{x^k}{1-x^k}\prod_{r=1}^{k-1}\frac{1}{1-x^{r(2k-r-1)/2}}.
```

積の添字を $`j=k-r`$ と置き換えると、

```math
\frac{r(2k-r-1)}{2}=\frac{(k-j)(k+j-1)}{2}.
```

よって、空分割の寄与1を加え、すべての $`k\ge1`$ について足し合わせれば、提示の公式を得る。

なお、各項の最低次数は $`k`$ なので、任意の次数に寄与する項は有限個であり、この無限和は形式的冪級数として定義できる。

## 小さい値による独立検証

Python の整数演算で、総和が40以下の分割を小さい順に全列挙し、隣接差を直接比較した。その個数を提示の母関数の係数と比較し、総和と部分の個数の各組についてすべて一致した。

初項は次のとおりである。

```math
(a(0),\ldots,a(20))=(1,1,2,3,4,5,7,7,9,12,12,13,18,17,21,25,24,27,34,33,38).
```

例えば、4の対象分割は次の4個である。

```math
(4),\quad(1,3),\quad(2,2),\quad(1,1,1,1).
```

分割 $`(1,1,2)`$ の隣接差は $`0,1`$ なので、条件を満たさない。

有限範囲の計算は補助的な照合であり、すべての次数に対する正しさは上の一対一対応による。

## 分割の並べ方についての注意

英語の題名 “Number of partitions of n such that the successive differences of consecutive parts are nonincreasing.” を用いる際は、部分を小さい順に並べて差を取ることを明記すると曖昧さがない。

もし大きい順の部分 $`c_1\ge\cdots\ge c_k`$ に対し、正の向きの差 $`c_i-c_{i+1}`$ が非増加という意味なら、別の条件になる。その場合は同じ差の差の方法により、母関数は

```math
1+\sum_{k\ge1}\frac{x^k}{1-x^k}\prod_{r=1}^{k-1}\frac{1}{1-x^{r(r+1)/2}}
```

となる。実際、この条件では4の分割5個すべてが許されるため、提示の公式とは一致しない。
