# A320388 の g.f. の証明

## 主張

A320388: $`n`$ の分割で、相異なる部分からなり、隣り合う部分の差（部分を小さい順に並べたときの差）が狭義単調減少となるものの個数。

```math
\sum_{n\ge0} a(n)\,x^n = 1+\sum_{k\ge1}\frac{x^{k+k(k-1)(2k-1)/6}}{(1-x^k)\prod_{j=1}^{k-1}\left(1-x^{j(2k-j-1)/2}\right)}
```

（Vladeta Jovovic, Nov 26 2026）

## 証明

空分割が項 $`1`$ に対応する。以下、部分の個数を $`k\ge1`$ に固定する。

部分を小さい順に $`p_1<p_2<\cdots<p_k`$ とし、差を $`d_i=p_{i+1}-p_i`$（$`1\le i\le k-1`$）とおく。条件は

```math
d_1>d_2>\cdots>d_{k-1}\ge1,\qquad p_1\ge1 .
```

$`c_{k-1}=d_{k-1}`$、$`c_j=d_j-d_{j+1}`$（$`1\le j\le k-2`$）とおくと、条件は「$`c_j\ge1`$（$`1\le j\le k-1`$）かつ $`p_1\ge1`$」と同値で、$`(p_1,c_1,\dots,c_{k-1})`$ と分割は一対一に対応する。$`d_i=\sum_{j\ge i}c_j`$ である。

部分の和は

```math
\sum_{m=1}^{k}p_m = k\,p_1+\sum_{i=1}^{k-1}(k-i)\,d_i = k\,p_1+\sum_{j=1}^{k-1}c_j\sum_{i=1}^{j}(k-i) = k\,p_1+\sum_{j=1}^{k-1}\frac{j(2k-j-1)}{2}\,c_j .
```

よって $`p_1`$ は重み $`k`$、$`c_j`$ は重み $`w_j=j(2k-j-1)/2`$ を持ち、それぞれ $`1`$ 以上を独立に動く。$`k`$ 個の部分を持つ分割の母関数は

```math
\frac{x^k}{1-x^k}\prod_{j=1}^{k-1}\frac{x^{w_j}}{1-x^{w_j}} .
```

$`1\le j\le k-1`$ では $`w_j\ge w_{k-1}=k(k-1)/2\ge1`$ なので分母は退化しない。分子の指数は

```math
k+\sum_{j=1}^{k-1}\frac{j(2k-j-1)}{2}
```

で、これは最小の分割 $`p_1=1`$、$`d_i=k-i`$、すなわち部分 $`p_m=1+\binom{k}{2}-\binom{k-m+1}{2}`$ の和に等しい。直接計算すると

```math
\sum_{j=1}^{k-1}\frac{j(2k-j-1)}{2} = \frac{(2k-1)}{2}\cdot\frac{k(k-1)}{2}-\frac{1}{2}\cdot\frac{(k-1)k(2k-1)}{6} = \frac{k(k-1)(2k-1)}{6}
```

となり、指数は $`k+k(k-1)(2k-1)/6`$ である。$`k\ge1`$ について足し合わせ、空分割の $`1`$ を加えると主張の g.f. を得る。 $`\blacksquare`$
