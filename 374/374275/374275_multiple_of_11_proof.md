# A374275 の正の添字の項が 11 の倍数であることの証明

## 主張

[A374275](https://oeis.org/A374275) を、

```math
x^2+3xy+y^2=k,\qquad 0\le x\le y
```

を満たす非負整数解の個数がちょうど $`n`$ になる最小の非負整数
$`k`$ とする。このとき、

```math
11\mid a(n)\qquad(n\gt0)
```

が成り立つ。なお、$`a(0)=2`$ は 11 の倍数ではない。

## 1. 表現数公式

正整数 $`k`$ を

```math
k=5^t\prod_{i=1}^r p_i^{e_i}\prod_{j=1}^s q_j^{f_j}
```

と素因数分解する。ここで、

```math
p_i\equiv1,4\pmod 5,\qquad q_j\equiv2,3\pmod 5
```

とする。いずれかの $`f_j`$ が奇数なら $`k`$ は
$`x^2+3xy+y^2`$ で表現できない。すべての $`f_j`$ が偶数なら、

```math
D(k)=\prod_{i=1}^r(e_i+1)
```

と置く。

```math
\alpha=\frac{3+\sqrt5}{2}
```

とすれば、

```math
x^2+3xy+y^2=N(x+\alpha y)
```

である。整数環 $`\mathbb Z[(1+\sqrt5)/2]`$ は類数1であり、分解素数
$`p_i`$ の指数を共役な二つの素イデアルへ振り分ける方法が
$`e_i+1`$ 通りある。惰性素数の指数は偶数でなければならず、分岐素数5には
振り分けの選択がない。したがって、単数作用の半開基本領域に入る代表元の
個数は $`D(k)`$ である。

より具体的には、

```math
\varphi=\frac{1+\sqrt5}{2},\qquad N(\varphi)=-1,\qquad \alpha=\varphi^2
```

であり、全正値単数はちょうど $`\alpha`$ の整数乗である。ノルム
$`k`$ の各イデアルは全正値生成元 $`\beta`$ を持ち、$`\alpha`$ の適切な
整数乗を掛けることにより、

```math
1\le\frac{\beta}{\beta'}\lt\alpha^2
```

を満たす代表元を一意に選べる。$`\beta=x+\alpha y`$ と書くと、この
半開基本領域は $`x\gt0`$、$`y\ge0`$ に対応する。

$`k`$ が平方数なら $`S(k)=1`$、それ以外なら $`S(k)=0`$ とする。
基本領域の軸上の代表元は平方数の場合にちょうど1個あるため、正整数の
順序対による表現数は $`D(k)-S(k)`$ である。

座標交換 $`(x,y)\mapsto(y,x)`$ の不動点は $`x=y`$ である。この対角解は
$`k`$ が5倍の平方数の場合にちょうど1個ある。その指示関数を $`F(k)`$ と
すると、$`0\lt x\lt y`$ を満たす解の個数は

```math
\frac{D(k)-S(k)-F(k)}2
```

である。ここへ境界 $`x=0`$ の $`S(k)`$ 個と、境界 $`x=y`$ の
$`F(k)`$ 個を戻すと、$`0\le x\le y`$ を満たす解の個数 $`R(k)`$ は

```math
R(k)=\frac{D(k)+S(k)+F(k)}2
```

となる。

正整数は平方数かつ5倍の平方数にはなれない。実際、そのような整数があれば
5進付値が同時に偶数と奇数になる。そこで、

```math
A(k)=S(k)+F(k)
```

と置けば、$`A(k)`$ は0または1であり、

```math
R(k)=\frac{D(k)+A(k)}2
```

を得る。また、表現可能な $`k`$ について、$`A(k)=1`$ であることは、
すべての分解素数指数 $`e_i`$ が偶数であることと同値である。

## 2. 存在性と初期値

$`n\ge1`$ に対して、

```math
k=11^{2n-1}
```

とする。11は1 modulo 5の分解素数なので、

```math
D(k)=2n,\qquad A(k)=0
```

である。したがって、

```math
R(11^{2n-1})=n
```

となり、$`a(n)`$ はすべての $`n\ge1`$ について存在する。

$`k=0`$ では $`(x,y)=(0,0)`$ が唯一の解なので $`a(1)=0`$ である。
また、$`k=0,1`$ はそれぞれ1個の解を持つが、$`k=2`$ は解を持たない。
よって $`a(0)=2`$ である。

## 3. 11による整除性

$`n\ge2`$ とし、$`k=a(n)`$ とする。このとき $`k`$ は正であり、
$`R(k)=n`$ だから、

```math
D(k)+A(k)=2n
```

である。$`A(k)\le1`$ かつ $`n\ge2`$ より $`D(k)\ge3`$ である。
したがって、$`k`$ は少なくとも一つの分解素数

```math
p\equiv1,4\pmod 5
```

を素因数に持つ。

$`11\nmid k`$ と仮定する。11は1または4 modulo 5となる最小の素数なので、
$`k`$ を割る分解素数 $`p`$ は $`p\ge19`$ を満たす。その指数を
$`e\ge1`$ として、

```math
k'=\frac{k}{p^e}11^e
```

と置く。

$`p`$ と11はいずれも分解素数であり、惰性素数の指数は変化しないので、
$`k'`$ も表現可能である。分解素数 $`p`$ の指数 $`e`$ を、そのまま11の
指数へ移しただけだから、

```math
D(k')=D(k)
```

である。また、分解素数指数の偶奇の多重集合は変わらないので、

```math
A(k')=A(k)
```

でもある。したがって、

```math
R(k')=R(k)=n
```

となる。一方、$`11\lt p`$ だから、

```math
0\lt k'\lt k
```

である。これは $`k=a(n)`$ の最小性に反する。よって、すべての
$`n\ge2`$ について $`11\mid a(n)`$ である。

$`n=1`$ では $`a(1)=0`$ なので、やはり $`11\mid a(1)`$ である。
以上より、

```math
11\mid a(n)\qquad(n\gt0)
```

が成立する。

## 数値確認

[374275_01.c](374275_01.c) の初項は、

```math
2,0,121,2299,6061,43681,66671,33659659,187891,1266749,8067191,\ldots
```

であり、正の添字の項はすべて11の倍数である。この確認は上の一般証明とは
独立した回帰テストであり、証明の代用ではない。
