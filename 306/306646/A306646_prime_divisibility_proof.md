# A306646 の素数による整除性

[A306646](https://oeis.org/A306646) を、列 `k` の母関数が

```text
(k + 1 - x^k)/(1 - x^k - x^(k + 1))
```

である配列 `A(n,k)` とする。

## 定理

`p` が素数、`k >= 2` ならば

```text
p divides A(p,k).
```

## 証明

A306646には、`n > 0` に対して次の公式がある。

```text
A(n,k) = n * Sum_{j=1..floor(n/k)} binomial(j,n-k*j)/j.
```

`n = p` とすると、

```text
A(p,k) = p * Sum_{j=1..floor(p/k)} binomial(j,p-k*j)/j.
```

`k >= 2` なので、和に現れるすべての `j` は

```text
1 <= j <= floor(p/k) <= floor(p/2) < p
```

を満たす。したがって `p` は `j` を割らず、各分母 `j` は法 `p` で
可逆である。よって右辺の和は `p`-進整数であり、その外側に因子
`p` があるから

```text
A(p,k) == 0 (mod p).
```

`p < k` の場合は和が空で `A(p,k) = 0` となるため、この場合にも
結論は成立する。

なお `k = 1` では `j = p` の項が 1 を与え、
`A(p,1) == 1 (mod p)` となる。したがって仮定 `k >= 2` は必要である。
