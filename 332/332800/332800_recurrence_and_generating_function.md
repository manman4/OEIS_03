# A332800 の厳密な部分集合再帰と母関数表示

## 1. 定義

`a(n)` を `[n]={1,2,...,n}` の置換

```text
sigma = (sigma(1),...,sigma(n))
```

で、剰余列

```text
sigma(1) mod sigma(2), ..., sigma(n-1) mod sigma(n)
```

が弱増加となるものの個数とする。空置換を含めて `a(0)=1` とする。
これは [A332800](https://oeis.org/A332800) である。

2026-08-28 時点の OEIS には値と定義は掲載されているが、A332800 自身の
母関数や漸化式は掲載されていない。以下では、厳密な部分集合再帰と
多変数有理母関数による係数表示を与える。

## 2. 一般項を決定する部分集合再帰

空でない有限集合 `S`、`x in S`、非負整数 `t` に対し、`F(S,x,t)` を

- `S` の元をすべて一度ずつ使う順列で、
- 最後の元が `x` であり、
- 剰余列が弱増加で、
- 最後の剰余が `t` 以下である

ものの個数とする。一要素列には最後の剰余が存在しないので、すべての
`t>=0` に対して

```text
F({x},x,t) = 1.                                         (1)
```

`|S|>=2` なら、次の再帰が成立する。

```text
F(S,x,t)
  = Sum F(S\{x}, y, y mod x),                           (2)
```

ただし和は

```text
y in S\{x},  y mod x <= t
```

を満たす `y` 全体について取る。

A332800 の一般項は

```text
a(0) = 1,
a(n) = Sum_{x=1..n} F([n],x,n-1)    (n>=1).             (3)
```

で与えられる。

### (2) の証明

`F(S,x,t)` に数えられる順列の最後から2番目の元を `y` とする。最後に
追加される剰余は一意に

```text
r = y mod x
```

である。これは `r<=t` を満たす必要がある。また、剰余列全体が弱増加で
あるための必要十分条件は、`S\{x}` の順列の最後の剰余が `r` 以下である
こと、すなわちその前半が `F(S\{x},y,r)` に数えられることである。

最後から2番目の元 `y` による場合分けは互いに素で、すべての順列を尽くす
ので (2) が成立する。(3) では最後の剰余は必ず `0,...,n-1` のいずれか
であるため、上限を `n-1` とすれば全有効置換が数えられる。

### メモ化計算用の疑似コード

```text
F(S, x, t):
    if S == {x}:
        return 1
    total = 0
    for y in S without x:
        r = y mod x
        if r <= t:
            total += F(S without x, y, r)
    return total

a(0) = 1
a(n) = sum(F([n], x, n-1), x=1..n)
```

これは値そのものを定義から再列挙する式ではなく、同じ
`(S,x,t)` に至る前半をまとめる動的計画法である。状態数の粗い上限は
`O(n^2*2^n)`、遷移時間の粗い上限は `O(n^3*2^n)` である。実際には `t`
として現れる値が剰余に限られるため、状態数はこれより少ない。

## 3. 多変数有理母関数

頂点集合 `[n]` の完全有向グラフを考え、辺 `i -> j` (`i!=j`) のラベルを

```text
lambda(i,j) = i mod j
```

とする。置換はすべての頂点を一度ずつ通る有向 Hamilton 路であり、
A332800 の条件は辺ラベルが弱増加することと同値である。

可換変数 `u_1,...,u_n` を導入する。`0<=r<=n-1` に対し、`n` 次正方行列
`M_r` を

```text
(M_r)_(i,j) = u_j    if i!=j and i mod j = r,
              0      otherwise
```

で定義する。また

```text
s = (u_1,...,u_n),
1 = all-ones column vector
```

とする。形式的冪級数として

```text
B_n(u_1,...,u_n)
  = s * Product_{r=0..n-1} (I-M_r)^(-1) * 1,            (4)
```

と置く。積は `r=0,1,...,n-1` の昇順で取る。このとき

```text
a(n) = [u_1*u_2*...*u_n] B_n(u_1,...,u_n).              (5)
```

### (5) の証明

各因子は

```text
(I-M_r)^(-1) = I + M_r + M_r^2 + ...
```

と展開される。したがって (4) の一つの項は、最初の頂点を `s` で選んだ
後、ラベル0の辺を任意本、次にラベル1の辺を任意本、以下同様に進む有向路
を表す。これは辺ラベルが弱増加する路を一意に生成する。

辺で頂点 `j` に入るたびに `u_j` が掛かり、最初の頂点にも `s` により
対応する変数が掛かる。したがって `u_1*...*u_n` の係数を取れば、各頂点を
ちょうど一度ずつ通る路だけが残る。それらは条件を満たす `[n]` の置換に
ほかならない。

## 4. 1変数通常母関数の係数表示

通常母関数を

```text
A(z) = Sum_{n>=0} a(n)*z^n
```

とすれば、(4)-(5) から

```text
A(z)
  = 1 + Sum_{n>=1} z^n
      * [u_1*...*u_n]
        (u_1,...,u_n)
        * Product_{r=0..n-1} (I-M_r)^(-1)
        * 1.                                             (6)
```

(6) は係数抽出を伴う厳密な母関数表示である。ただし A022825 のような
単純な1変数関数方程式ではない。弱増加の場合、同じ剰余の反復が許され、
ある元を除いた後に任意の穴あき部分集合が残るため、現在のところ
`a(0),...,a(n-1)` だけで閉じる単純なスカラー漸化式は得られていない。

## 5. 既知値との照合

(1)-(3) をそのままメモ化して計算すると、`0<=n<=17` で

```text
1, 1, 2, 4, 9, 21, 44, 109, 241, 530, 1176, 3180,
6456, 14835, 34672, 81877, 179434, 479275
```

となり、A332800 の既知値と一致した。この一致は再帰の証明とは独立な
実装確認である。
